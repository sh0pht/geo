# GeoCAD 0.2 — Windows installer build

Это **исходный проект с автоматической сборкой EXE-установщика**, не готовый установщик. Сборка на Windows ещё не проверена.

## Получить GeoCAD_Setup.exe без установки инструментов на ПК
1. Создайте пустой репозиторий на GitHub и загрузите **содержимое** этой папки в корень репозитория, включая скрытую папку `.github`.
2. Откройте вкладку **Actions** → **Build GeoCAD Windows installer** → **Run workflow**.
3. Дождитесь зелёной отметки, затем скачайте артефакт **GeoCAD-Windows-Setup** и распакуйте ZIP.
4. Запустите `GeoCAD_Setup.exe` на Windows 10/11 x64.

Если сборка завершится ошибкой, установщик не появится: пришлите журнал ошибки для исправления. GitHub Actions на некоторых аккаунтах может требовать включения и иметь ограничения использования.

## Возможности прототипа
Тёмный классический/ленточный интерфейс, перетаскиваемые панели, навигация по полю, чтение только сущностей LINE из текстового DXF. Это не готовая замена AutoCAD. DWG, LAS/LAZ/E57, полноценное редактирование и GPU-движок ещё не реализованы.
